# Implementation decisions

Whisp is a static Vite + React + TypeScript application. No server, cookies, persistent draft storage, analytics, cloud AI APIs, runtime font services, or credentials are needed. Optional voice typing caches public model assets separately from writing.

- An explicit reducer owns the ritual: landing → entering → writing → releasing → complete, with returning → landing for home navigation. Entry and release callbacks cannot advance an unrelated stage. Text remains intact until the animation reports completion. A failed animation restores editing.
- Canvas 2D renders original cosmic artwork and particles. This keeps the bundle small and avoids WebGL contexts, shader compilation, and a second renderer fallback. CSS provides a quiet fallback when canvas is unavailable. CSS handles portal choreography; requestAnimationFrame handles the continuous effects. No animation library is needed.
- A native textarea handles writing, IME, selection, undo, mobile keyboards, and scrolling. At release, a temporary DOM mirror measures browser-wrapped text (including grapheme clusters); an offscreen canvas renders the visible lines using the editor's actual font and metrics. Sampled ink pixels seed bounded particle arrays. Only the visible region is animated for long entries; the full entry is retained for undo.
- Breath detection uses local RMS, spectral flatness from 45–6500 Hz, low/high energy distribution, normalized pitch autocorrelation, crest factor, and sustained confidence. Lower-percentile quiet calibration ignores brief early puffs; downward adaptation recovers when the room quiets. Separate broadband and low-frequency turbulence evidence accommodates how actual blowing hits microphones. Normal and Gentle breath configurations are user selectable. The microphone preference starts on, is disclosed beside Enter, and requests permission inside that click; calibration begins in the notebook, and only a nonempty draft arms release. It is a heuristic, not a speech classifier. Calibration needs quiet; loud fans, whispered speech, or unusual microphones can fool it. Listening is explicit, stoppable, and ends on release, hidden tabs, disconnect, or unmount. All release methods share the same sequence and undo.
- Reduced motion skips camera travel and uses a short ink fade rather than particle movement. Sound is on by default but waits for the entry click to create/resume its AudioContext. The 8.8-second journey gets a locally composed ascending chime. Notebook music uses slow extended chords, sustained sine voices, sparse bell notes, and an original convolution reverb. A bounded lookahead timer schedules the score. While microphone listening is active its level is reduced; candidate breath progress rapidly ducks the music to reduce speaker leakage before the sustained gate can fire. Echo cancellation is requested, while noise suppression and automatic gain are disabled to preserve breath. Hidden tabs dispose both audio contexts; explicit controls resume playback/listening.
- Released text is held in reducer memory for 20 seconds. Beginning again, returning home, or expiration drops that reference. The textarea is remounted after completion to discard its native edit history before a new draft. JavaScript does not offer guaranteed secure memory wiping. Drafts are lost on refresh; beforeunload warns while an unreleased draft exists, subject to browser support.
- Fonts are bundled through Fontsource. Caveat is used for handwriting; system fonts cover unsupported scripts. Cormorant Garamond and DM Sans provide editorial and interface typography. Their OFL licenses ship in the font packages and are included in the project notices.

## Performance budget

Starfield: <= 220 stars on desktop / 95 on narrow screens or devices reporting <= 4 logical cores. Ink: <= 4,200 particles on desktop / 1,800 on narrow screens or those devices, sampled from a viewport-sized canvas. Canvas DPR capped at 1.5–2. No full-document rasterization or per-character live editor DOM. Hidden-page animation pauses. FPS is a target, not a verified device guarantee.

## Voice, quotes, and seamless arrival

The invitation uses 100dvh with header/footer included, retaining a 100vh fallback. Typography and spacing adapt to viewport height as well as width. Below 470px height, scrolling takes priority over clipping controls (including when zoom reduces the effective viewport).

The final 1.6 seconds of the 8.8-second journey mount a read-only notebook under an opaque warm portal. `PortalTransition` measures its actual paper rectangle in a layout effect and animates the glow from the viewport into that rectangle, then fades the glow. The editor is armed only after arrival. Surrounding controls fade in separately. Skip uses a short quiet reveal. The travel layout retains its homepage dimensions to avoid a jump at the initial click.

`useVoiceWriting` captures PCM through a same-origin AudioWorklet, never MediaRecorder or a remote speech API. It sends bounded phrase segments to a lazy module worker. A short silence ends a phrase; a 12-second boundary adds a small overlap, which is deduplicated when recognized text is appended. Backlog pressure pauses capture rather than silently discarding captured phrases. Finishing stops device input, flushes the last partial worklet block, and waits for queued recognition. Cancel drops pending buffers, terminates the worker, and preserves text already on the page. Generation guards reject late permission grants/results. Backgrounding stops input; captured pending phrases may finish locally. The worker is disposed when finished, releasing its model and input tensors.

The speech pipeline is pinned to Transformers.js 3.8.1 for same-origin/local-only model compatibility. Its image-only `sharp` dependency is overridden to a patched release; it is not used in this browser app. ONNX uses WASM in a worker with one thread, so cross-origin isolation and cloud services are unnecessary. `env.allowRemoteModels = false`; model/runtime URLs are same-origin. No fallback sends audio elsewhere. The cache namespace `whisp-voice-model-v1` stores public model files only. Successful release or return home automatically deletes only that namespace; Help offers a manual retry. Cache failures are reported without blocking the ritual. Workers are terminated before automatic clearing, and undo remains independent. Speech-asset fetches use no-store; included host headers reinforce that policy. Ordinary app-code HTTP caching remains separate.

The model is English Whisper Tiny, converted to q8 ONNX by Xenova, pinned to revision `79fb389fc764e7c395bd330e9531d9d32ada7049`. Preparation downloads it once during development/build; generated assets are ignored by Git and included in the static output. A manifest records sizes/hashes. First voice use loads roughly 70 MB from the site. Accuracy/CPU/memory requirements are real limitations, especially on low-powered phones or emotional/unclear speech. Typed input always remains available. Runtime asset caching is distinct from draft persistence.

The 100 quotes are original writing across ten themes. Matching is deliberately limited to local keywords, with bounded text scanning and no user profile. A deck retains only quote IDs for random selection without repetition. A quote is chosen when release is requested; no thought text is copied into quote metadata. It survives undo expiry without retaining the released writing.

The score adds a dedicated effects bus: gentle writing texture, swept filtered noise for wind, staggered puffs following dissolution, and a completion chime. No text is passed into the audio system. All effects obey the one sound preference. Voice typing mutes output to avoid self-transcription; breath candidates duck music. Audio tests render effects offline and check non-silent, bounded output.


## Follow-up interaction details

`cleanSpeechTranscript` suppresses known non-speech labels only in recognized output. Bracketed annotations and standalone label segments are removed; meaningful sentences about music/crying and all native keyboard edits survive. Near-zero/short PCM blocks skip inference. Filtering is applied at the worker boundary and append boundary; this reduces annotations without claiming to detect every hallucination.

The notebook gives the next action above the paper, with dynamic guidance while voice input is active. Input/progress feedback stays visible; sensitivity and recalibration are optional troubleshooting. Layouts retain scrolling on short or zoomed screens, and long notice/status text can wrap.

`ReturnJourney` measures the paper once, expands a warm glow to the viewport for 1.25 seconds, then retreats into the home starfield for 2.35 seconds. The home scene is mounted behind the glow and settles into place. Star movement and a descending score reinforce the reverse direction. Enter remains disabled until return completes; Skip return and a 180ms reduced-motion fade restore focus to Enter. Only completion or an empty inactive notebook may return home. Returning drops undo immediately and cancels input.


## Public HTML and production identity

The build pre-renders `App` in its empty landing state through a separate Vite SSR transform with dependency discovery, file watching, HMR, and WebSocket listening disabled. Its cache directory is separate from the local development server. Static output includes the same public invitation every visitor sees; no browser draft, audio, or notebook state enters the build.

The client hydrates existing production markup and creates a fresh root during development. `useReducedMotion` uses `useSyncExternalStore` with a deterministic server snapshot, then applies the visitor’s preference without a hydration mismatch. The build gate validates the initial HTML, self-hosted assets, production canonical/developer identities, structured data, favicon/share dimensions, and host policy parity.

Search/share metadata and structured data live in `index.html`. The single production URL is `https://whisp.rubangino.ca/`; developer links point to `https://labs.rubangino.ca/`. Hashed bundles are immutable, HTML revalidates, and speech downloads retain their no-store policy. No service worker or offline-PWA behavior is claimed.
